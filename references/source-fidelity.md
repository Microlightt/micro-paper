# 来源核查

extract 的栏序和段落是候选，不是语义判断。先看全部原页，比较原字形与候选块，修正跨栏、跨页、图注续段和标题。清单记录所有原字形；图内标签及页眉页脚的排除理由必须具体。

扫描或字体映射异常会进入复核队列。Agent 依据页图转录正文并逐字核查，保留 bbox、sourceEvidence 和 transcription 标记；图中文字仍保持原图。不可辨认就保留 blocked，不用英文复制充当中文。表格保持行列关系，公式不能用猜测的文本替换；如无法可靠重排，使用原公式图像配完整对应文字译文并标出表示方式，否则阻塞。

科学格式由 fontname、size、baseline 与原页视觉证据恢复。脚本提供斜体候选，不机械给基因名加斜体。上下标逐处核对，中文格式由 Agent 对应到译文区间。不要改变希腊字母、数字、负号、比较符号、单位和引用编号。

crop 的坐标为原页显示坐标 PDF point；裁切必须覆盖图边界、英文面板与图例，不包含无关正文。默认 scale=4，细节不足时提高或提供原始嵌入图资源。内联原 PDF 供放大与字形核对，不能据此免除正文翻译。对矢量、透明度、遮罩、渐变和小标签检查实际图像，图失真则停止。

按实际图号登记 main/extended/supplement，面板用 a–z。显式图号解析可处理 Fig./Figs./Figure、Extended Data Fig.、范围和复合引用；检查 parse 输出，未覆盖的出版格式由 Agent 提供 inlineReferences（freeze 的 `--keep-references` 保留人工索引），不要按主题猜图。无引用段落沿用前文最近一次明确引用。所有明确关联图均须可访问；当前图在选择器中，其余多图候选提供按钮，单图不重复标签。

v1.2.0 将完整规范图注移动到右侧浅绿区域，不能因此删字、复制第二份图注或改变 blockId/UTF-16 区间。共享或跨页图注仍按来源核查，保留全部续段；无法归属就保留并提示，不为界面整齐猜图。省略生成的重复章节标题前，必须确认章节内首个可见来源 heading 的两种语言均与章节标题在归一空白后完全匹配，原文标题块始终保留。技术上显示、搜索与笔记正确，仍不能证明图注翻译或全篇科学结论已审校。仅执行阅读交互修改时，如实保留完整科学审校未执行的范围，不把技术通过升级为科学审校通过。
