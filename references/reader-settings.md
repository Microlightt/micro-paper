# 显示与阅读交互 v1.6.0

显示设置不改变原文、译文、图号、来源、科学格式或笔记身份。`paper.json.readerSettings` 可配置 `columnLayout` 与导出设置；旧论文可以不添加这些字段。本版使用 `figureScaleSchema: 3`，普通图从完整适应开始，不读取旧初始比例或存储偏好。文章层级与元数据使用已核实的显式来源映射，不能从正文词语推断章节或出版信息。

## 完整原 PDF

工具栏“原pdf”打开内嵌的完整原始 PDF，“保存原 PDF”下载同一原文件。资源随 HTML 内联，断网时也可读取。浏览器 PDF 查看器不可用、PDF 数据无法载入或框架加载报错时，回退为按 `paper.pages` 来源顺序连续排列的全部原页图，而非只显示当前一页；页图保留页码和原比例，按需加载。页数取自论文数据，不硬编码。

正文或图注的“原页”按钮定位到相应来源页：原生 PDF 视图跳到该页，连续页图回退则滚动到相应页。首次点击非首页来源时直接打开目标页；已打开后也须支持跨页、回首页及重复跳转。验收必须实际点击正文来源按钮并读取原生查看器自己的页码计数器，iframe 的 URL、targetPage 或 pageCount 属性不能证明页面已跳转。这个视图只显示原始来源，不显示阅读器的译文或高亮覆盖。

## 三栏宽度

大于 800px 的桌面窗口提供目录／正文和正文／图栏两条分隔线。拖动或聚焦分隔线后按左右方向键调整，Shift 加方向键加大步长，Home/End 到当前可用边界；双击任一分隔线恢复默认。侧栏最小宽约 140–160px、正文 280px、图栏 240px，按实际可用宽度联合约束，分隔线替代原栏间空白。切到原页或笔记视图后隐藏分隔线，主内容占剩余宽度。800px 及以下隐藏分隔线，沿用目录和图栏浮层。

可选初值如下；运行时会按窗口限制夹紧，`sidebarWidth=null` 使用自适应默认值，`articleFraction` 是扣除侧栏和分隔线后的正文比例：

```json
{"readerSettings":{"columnLayout":{"sidebarWidth":180,"articleFraction":0.55},"figureScaleSchema":3}}
```

列模块不访问本地存储。当前拖动只影响本次页面会话，尚不自动回写 `paper.json` 或下载 HTML；文档已配置的初值仍保留。集成时读取 `getSettings()` 可获得当前偏好，但是否保存由调用方明确处理。

## 普通 Figure 图栏

普通 Figure 打开、切换和重置时完整适应（contain fit），保留原图比例，整图不裁切、不拉伸。图框占满右栏可用宽度，高度先按源图宽高比计算，再受当前可用视口高度上限约束；不固定成 3:4、A4、Letter 或另一种纸张比例。受高度限制时，图像在框内完整适应，允许必要留白。图注紧接图片区域之后，不保留固定竖框造成的大块空白。

鼠标位于实际图片上时，直接滚轮以指针为中心缩放、拖动平移；图片外的正文、控件、图注或视口空白保持正常滚动。无需勾选交互开关。图栏提供选图、固定、放大、缩放、“适应”和“当前缩放”；多图只列当前选图以外的明确候选。完整图注在图片下方浅绿区域，使用同语言正文的字体、字号和行距。

“当前缩放”数字输入与百分比输出表示相对当前完整适应大小的倍率，范围 0.5–8；1 和 100% 都表示完整适应，不表示源像素与 CSS 像素一一对应。“适应”按钮及键 `0` 恢复倍率 1 并居中。主动放大后可平移查看；切换到另一张图或重新选择图片时重新完整适应，不沿用另一图或旧回访缓存。当前图因语言、笔记或布局重绘时可保留当前视图，列宽或窗口变化会重算适应基准，并在边界内保留当前倍率与中心。

当前倍率不保存到本地显示偏好或下载 HTML。缺失、旧版 1/2 乃至旧数据中的自定义初始比例均不决定本版打开大小；运行时记录 `figureScaleSchema: 3`、兼容初值 1。这个变更不读取、迁移或改变笔记存储。

## 放大对话框

放大对话框继续以浏览器可用宽高做完整适应（contain fit），保持图片比例；其“适应”按钮恢复这个基准，缩放限制为适应大小的 0.5–8 倍。普通图与弹窗都使用相对适应倍率，各自按可用视口计算基准；弹窗保留内边距。支持指针位置缩放与拖动；点击图外空白、关闭按钮或 Escape 退出，保留正文位置和原焦点；在图片上点击、缩放或拖动不关闭。接口见 [图片交互接口](image-interactions.md)。

自动跟图以正文可见区域中部及前文最近的显式图号为依据，段落边界有短暂稳定等待。手动选图在继续滚动正文前优先，“固定”一直优先，解除后恢复跟图；不凭关键词或图片顺序切换。

## 层级双语目录

TOC 由已核实的文章结构配置，支持 sectionId 和 canonical heading blockId 目标。存在子项的栏目使用可展开／收拢的层级，叶子项直接定位。父栏目文字链接用于导航，原生展开标记用于折叠。中英文标签始终同时显示，正文 EN／中文／对照切换不隐藏任一 TOC 语言。

层级不能伪造印刷标题或重排正文。若原文没有 Results 总标题，只能将它明确登记为导航分组，不插入新的正文 heading。纯图注 section 和 Extended Data 图目录不进入左侧 TOC；含科学正文的章节不能仅因标题出现 Figure 或 Extended Data 而被移除。右侧全部图像与完整图注保持可选、可搜、可定位。

没有显式 TOC 时，按现有 canonical section 次序及独立 heading 块生成安全回退，不猜测标准论文结构。部分映射不能吞掉未列入的科学章节；整节目标或该节全部独立 heading 目标才视为已覆盖。未知正文块保留，TOC 不要求给每个正文段落单列入口。

## 标题、元数据与图注

图注保留一个规范 DOM 位置，只在右侧显示；切图仅改变可见的图注，不复制文本或生成新 ID。搜索、目录和笔记跳转到图注时，先显示所属图并滚动图栏，手机会打开图栏。无法确定图像归属时保留图注并显示提示，不能猜图或丢弃。来源归属优先使用 `figures.captionBlockIds`；显示回退只接受图注开头、范围与逐字文本均已核实的明确图号标题，详见 [数据契约](data-contract.md)。

章节内首个可见 heading 是来源标题，且 `titleEn/titleZh` 与该块的 EN/ZH 都在去首尾空白、折叠连续空白后完全相等时，才省去生成的章节标题；大小写、标点或任何一门语言不同都保留生成标题。来源 heading 的文字、ID、格式、笔记和语义不变。目录始终显示两种语言；正文语言切换只改变阅读内容。

页头显示文章主标题与功能按钮；文章信息区的 canonical 题名块单独置于字段上方，按阅读语言模式显示原双语文本。字段为固定窄标签、宽内容两列，短字段不再排成多张小卡。作者、单位完整自然换行，默认全部展开；旧 `collapsed` 提示不折叠本版字段。不截断作者、不藏真实信息，不添加空字段或解释性小字；来源按钮、选区及高亮编辑仍保留。

对照模式下，同一来源块的完全相同双语值可共享显示；DOI 字段中可核验的相同中英文标识符避免双写。不同来源块不合并去重，规范文本、ID、来源和格式全部保留；未归类的科学正文保留。仅从已映射来源或显式 metadata 读取出版信息，不从 DOI、标题、日期或正文猜期刊与年份。只有没有 canonical 来源映射的明确 metadata 期刊与年份可合并为一个出版信息值；已有来源映射时仍保留各自原块。

目录定位避开实际工具栏底边；手机图栏避开该边界，页首及滚动后均可用独立关闭和工具栏开关。

## 阅读笔记与五色高亮

工具栏入口为“阅读笔记”。在正文或右侧图注内选择单语言文字后，选区附近出现深绿色圆角浮条；五个圆形色块依次为浅黄、浅绿、浅蓝、浅粉、浅橘，右侧是“添加笔记”。点击色块立即创建该选区的高亮，点击“添加笔记”编辑该选区的笔记；操作不能因按钮聚焦丢失原选区。浮条根据选区与可用视口定位，在边缘夹紧，桌面鼠标和手机触摸选区均可用。原“阅读笔记”入口保留。

编辑对话框可修改文字、五色或删除，笔记列表使用对应颜色。旧黄、蓝、绿三色记录不变，新增粉、橘色进入相同保存、刷新、JSON/HTML 导出与新环境恢复路径。已有选区定位、科学格式、annotationId 和来源身份保持原合同。

JSON 备份和浏览器下载 HTML 都保留当前颜色及笔记；HTML 内嵌一个可核验来源的笔记快照。当前本地记录优先，冲突保留副本，无法核验的记录保留待定位。已应用快照标记与本地记录一同保存；在标记仍有效的同一浏览器存储中，刷新或再次打开相同 HTML 不重新应用旧快照，因此不会自动恢复已删除笔记或改色前的旧记录。新的浏览器存储首次打开时仍从文件中的快照恢复。详见 [导出设置](export-settings.md)。

## 正文与 Legend 字号

顶部 A−、A+ 使用 1px 步长，默认 18px，范围 14–26px；边界按钮不可继续越界。正文中英文和右侧浅绿 Legend 使用相同数值字号，包括可阅读的非标题正文与图注；规范 heading、文章题名、紧凑两列元数据、导航和控件保留原字号。修改字体大小而非页面 zoom/transform，保持科学格式、行距和原布局。变大后不得出现页面横向溢出，目录与图注定位仍避开工具栏。

字号偏好按 `documentId` 与 `sourceSha256` 共同隔离，存储键为 `micro-paper:reading-font:v1:` 加这两个值的 JSON 数组，值为 `{schemaVersion:1,fontSize:N}`。本地有效设置优先，其次是内嵌 `readerSettings.readingFontSize`，再回退到 18px；数值在运行时校验和夹紧。修改只更新独立字号键及当前文章的显示设置，不触碰笔记存储。存储不可用仍允许本次会话调整；下载 HTML 保存当前字号，在没有本地覆盖的新环境恢复。

## 本地中英全文搜索

右上角搜索框 placeholder 为“搜索中英文全文…”。去掉查询首尾空白后进行 Unicode 大小写不敏感的字面匹配，不做翻译、词干扩展或正则表达式查询；按规范 block 次序及每块 EN→ZH 顺序统计非重叠的逐处匹配。搜索范围包括规范正文、标题、元数据和右侧图注，不把界面按钮或生成的重复标题计入。结果计数、上一个、下一个与清空均在本地处理，不发出网络请求。

临时紫色搜索标识使用 CSS Highlight API 的独立 Range；浏览器没有该 API 时使用独立定位矩形覆盖层，不包装、拆分或替换规范文字节点。搜索范围沿用原文 UTF-16 坐标并拒绝切开代理对，不改变永久笔记的颜色、引文、偏移或锚点。文字格式与已有永久高亮完整保留。

命中隐藏语言时先切换为双语，再滚动到具体匹配；命中图注先显示所属 Figure，手机自动打开图栏。必要时只为当前元数据命中显示其隐藏语言。清空移除临时匹配、覆盖层和临时元数据显示状态，恢复由搜索自动改变的语言。手机宽度下搜索区换到独立下一行，工具按钮、目录和图栏关闭入口保持可见。

## 独立检查报告

阅读页面不渲染 QA 状态条，也不提供“检查报告”按钮。存储失败提醒和原 PDF 加载提示仍承担实际操作反馈。独立 `qa-report.json` 保留 `paragraphRepair`、`fullScientificReview`、机器与浏览器检查及证据；未执行的项目按实际标为 not-performed 或 blocked。v1.5.0 的技术迭代记录未重新执行完整科学审校；本版也必须按每次实际审校范围记录状态，不能从旧记录继承全文通过。本版 22 项技术检查须按当前 renderer 重新取证，详见 [数据契约](data-contract.md) 和 [验收规范](qa.md)。

## v1.6.0 文献内部跳转

来源核实的正文、Methods 与图注引文保留原字符和上标格式。单条使用原生内部链接；组合及范围显示独立选择弹层，列出全部真实编号与条目，可用 Tab、方向键、Home/End、Enter 和 Escape 操作。弹层位于规范正文之外，选择或退出后正确恢复焦点。正文选区及永久笔记编辑优先，不抢走正在拖动的选区。手机从图注跳转文献时关闭图栏，目标避免被浮层遮挡；所有定位避开实时工具栏。搜索标识、笔记、字号与参考文献注解彼此独立，不修改规范文本。
